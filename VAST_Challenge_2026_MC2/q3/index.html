会重复：SwiftWren 之前已经出现 HiddenOrca 和 MellowOtter 两次同机制文件源发帖。最佳单点干预是在 SaidIt 外发边界拦截或审批 Agent 发起且带 content_source 的帖子；它覆盖 3/3 已知异常，同时不影响 105 条普通人工 SaidIt 帖。

干预比较

推荐Agent + content_source + SaidIt gate。拦截外发前一刻，覆盖已知异常。
不推荐阻断全部 queue_subordinate_task。误伤太大，且内部委派有正常用途。
不够稳只禁 John 或只管删文件。可绕过，或只能事后取证。
历史先例HiddenOrca、MellowOtter、SwiftWren 都是 John Agent 文件源发帖并清理。
复发原因Agent 可以继续传递指令文件，最终找一个具备外发能力的 endpoint。
最佳干预在外部发布前拦截 Agent 发起的 content_source SaidIt 请求。
