How a file-backed Agent workflow escaped to SaidIt

This overview establishes normal behavior before isolating the target anomaly: John Windward's Agent posted a file-backed message to SaidIt on May 17, 2046 04:21 UTC-7. The page uses counts, ratios, and linked evidence from MC2 data.json and org_chart.json.

Conclusion: an internal document was packaged as a codename text file, relayed as an Agent read_file task, posted through saidit_post(content_source), then cleaned up. The same mechanism appears three times.

Investigation Finding

The anomaly is not a normal human forum post. It is the rare combination Agent actor + saidit_post + details.content_source, which occurs in exactly three SaidIt posts in this data.
